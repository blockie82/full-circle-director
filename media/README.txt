Put your videos and 360° images in this folder, or add them from the control panel.

Videos: MP4, WebM, MKV or MOV. Images: JPG, PNG or WebP.
Put a set of files in a folder inside this one (for example "Gallery tour") and the panel shows them as a group you can step through.
Name files with _180, _TB or _LR (or _SBS) and the panel will guess the format. You can change it in the panel.
