Full Circle Director setup guide

By Full Circle Immersive. Play 360°, 180° and 3D video on up to 8 Quest headsets at once, controlled from one Windows PC over your local network.

OnceSet up the PC

  1. Install Node.js (the LTS version) from nodejs.org. Accept the default options.
  2. Unzip this folder somewhere permanent, for example C:\FullCircle.
  3. Make sure the PC's network is set to Private: Settings → Network & internet → your Wi-Fi or Ethernet → Network profile type → Private.
  4. Give the PC a fixed address on your network. In your router's settings this is usually called a DHCP reservation or static lease. See the note below for why this matters.
  5. Double-click START.bat. The first time, Windows Firewall asks whether to allow Node.js. Tick Private networks and click Allow.

A black window opens showing the addresses, and the control panel opens in your browser at http://localhost:8080. Leave the black window open while you work. Closing it stops the server.

Why a fixed address matters. Each headset stores downloaded videos against the PC's address. If the PC's address changes, headsets treat it as a new server, accept the security warning again, and need the videos downloading again.

Once per headsetConnect a Quest

  1. Connect the headset to the same Wi-Fi network as the PC.
  2. Open the Browser and type the address shown at the top of the control panel, for example https://192.168.1.20:8443.
  3. The browser warns that the connection isn't private. This is expected, because the PC made its own security certificate. Choose Advanced, then Proceed.
  4. The page that opens is Full Circle Player. Bookmark it so it's one tap next time.
  5. Optionally give the headset a name on its page (or rename it from the control panel), such as "Headset 1".

Each sessionRun a showing

  1. Add videos and 360° images with Add files or Add folder in the panel's Library, or drag them onto it. (You can also copy them into the media folder yourself.) Images can be JPG, PNG or WebP, and use the same naming as videos for 180° and 3D.
  2. Check each video's projection and stereo layout in the Library and correct them if the guess is wrong.
  3. Click Send to headsets. Each headset copies the video into its own storage, so playback never depends on Wi-Fi speed. You only do this once per video.
  4. Click Load. The panel shows "Ready on 8 of 8 headsets" when everyone has it.
  5. On each headset, press Enter VR. Each headset turns to face the centre of the video automatically.
  6. Press Play. All headsets start together about a second later.

While it plays, each headset's view shows as a coloured marker on the panel's preview. Click a headset in the list to see roughly what its wearer sees. View all headsets shows every wearer's view side by side in a grid; press Esc to close it.

To point everyone at something, click that spot on the preview, then press Turn everyone to this point. Each wearer's view turns left or right so the spot is straight ahead of them; up and down stay level so the horizon doesn't tilt. Recentre everyone turns everyone back to the centre of the video, and a wearer can recentre themselves by squeezing the grip button.

Showing a series of photos. Put them in a folder, for example by choosing Add folder. The folder appears in the Library as one line that opens to show its contents, with Send folder to headsets. Load the first item, then use Previous and Next beside the play controls to step through. A presentation clicker works too, since its buttons send Page Up and Page Down.

Keyboard shortcuts in the panel: Space plays and pauses, ← and → skip 10 seconds, Page Up and Page Down step through a folder.

Files and formats

WhatRecommendation
Where files liveThe media folder next to START.bat. Files can sit in it directly or one folder down; each folder shows as a group in the Library. Folders inside folders aren't read.
8K 360°MP4, H.265 (HEVC), 30 fps. 8K at 60 fps is at the limit of what a Quest 3 can decode.
3DTop-bottom or side-by-side in one file. Add _TB or _LR to the file name and the panel picks it up.
180°Add _180 to the file name.
360° imagesJPG, PNG or WebP, 2:1 for 360° (for example 8192 × 4096). Very large images are scaled down to what the headset can display.
Flat videoAdd _flat to the file name. Screen distance and width are set in the panel.

If you replace a file with a new version of the same name, headsets see that it changed and need it sending again.

Preview copies for slower PCs

Headsets always play the full-resolution original. The control panel only needs a picture to show where people are looking, so for heavy videos (wider than 4K, or in a format such as H.265 that many PCs struggle with) Full Circle Director makes a light 1080p copy in the background and previews that instead. You'll see "Making preview copy" and then "Preview copy ready" in the library.

You don't need to do anything. Copies are made, named and stored automatically. You don't create, rename or resize them yourself.

  • Time: it happens once per video. On a slow laptop an 8K video can take longer to convert than it lasts, so add videos well before a session. You can still run a session while a copy is being made; the preview just shows the grid until it's ready.
  • Disk space: a copy is roughly 10 MB per minute of video, whatever the original's size, so a 10-minute 8K film needs about 100 MB extra.
  • Where they're kept: the proxies folder next to START.bat. The file names are codes, so don't rename anything in there. You can delete the whole folder at any time; copies are simply made again.
  • Changing a video: if you replace a video with a new version, or rename it, a fresh copy is made and the old one is removed automatically.
  • Using a faster PC: you can make copies on a faster PC and copy the proxies folder across, as long as the video files are identical: same name, same size, and copied rather than re-saved.
  • Doing it by hand: open a video in the library to remake its copy, or to make one for a video that wasn't picked automatically.
  • First run: the first time you run this version, START.bat downloads the free ffmpeg tool that makes the copies. It needs internet once.

If something isn't working

  • Headset can't open the address. Check it's on the same Wi-Fi as the PC, the black server window is open, and Windows Firewall allows Node.js on Private networks.
  • "Video missing" on a headset. Click Send current video on that headset in the panel, or tick Stream to headsets that don't have the video as a stop-gap. Streaming works for smaller files but not 8K to several headsets.
  • Sound off on a headset. The browser needs one tap before it allows sound. Ask the wearer to tap the page, or to press Enter VR, which counts.
  • A headset drifts out of sync. The "Sync" figure on its card should stay within ±40 ms. If it keeps growing, the video is too heavy for that headset; try an H.265 or lower frame-rate version.
  • Picture looks mirrored or markers are on the wrong side. Tell your developer; it's a one-line change.
  • Port already in use. Another copy of the server is running. Close it, or change the ports in config.json.
